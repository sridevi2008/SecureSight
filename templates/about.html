Welcome to SecureSight

SecureSight is a phishing email analysis system designed to identify potentially malicious and legitimate emails using machine learning techniques. It analyzes email content and provides useful insights through an interactive dashboard and visual analytics.

🛡️

Overview

🎯

Project Objective

To identify suspicious emails and help users understand potential phishing threats through automated email analysis.

🧠

Machine Learning

Uses a trained machine learning model to classify submitted email content based on patterns learned from its training data.

📊

Data Visualization

Presents email statistics, suspicious keywords, sender domain information and analysis charts through a visual dashboard.
